# Example: FastAPI app with migration tests

The project behind the [FastAPI](https://anon-000.github.io/mongomig/recipes/fastapi/) and
[Test your migrations](https://anon-000.github.io/mongomig/recipes/testing/) recipes:

```text
app/models.py                 an Order model registered with @collection
app/main.py                   FastAPI app: migrations at startup + /health/ready
migrations/versions/          an autogenerated revision and a custom one (ctx.batches)
tests/                        pytest: full history up/down, one migration's logic, the app
```

```bash
pip install -r requirements.txt
docker compose -f ../../docker-compose.yml up -d --wait
pytest -v tests
```

MongoMig's own CI runs these tests on every change.
