# Example: FastAPI + Beanie

Beanie documents need no MongoMig-specific declarations. The collection names (`Settings.name`),
`Indexed(...)` fields and `Settings.indexes` are read from the classes, and the `beanie`
storage profile (dates as BSON dates, `Decimal` as decimal128, `UUID` as binData) is applied
automatically.

```text
catalog/models.py          Beanie Documents
catalog/main.py            FastAPI app; init_beanie(skip_indexes=True): MongoMig owns indexes
migrations/env.py          target_metadata.register_beanie(*DOCUMENTS)
migrations/versions/       autogenerated: collections + all declared indexes
```

## Try it

```bash
pip install -r requirements.txt
export MONGODB_URI="mongodb://localhost:27017/?directConnection=true"

mongomig models        # how MongoMig sees your Documents
mongomig plan
mongomig upgrade       # run as a deploy step, not at app startup
uvicorn catalog.main:app --reload
```

Change a Document (e.g. add `stock: int = 0` to `Product`), then run
`mongomig revision --autogenerate -m "add stock"`. The generated migration backfills
`stock: 0` into existing products.
